Sobre nosotros

Nuestra WiTiendita es un espacio dedicado a los regalos y detalles especiales para sorprender a las personas que mas queremos.

Buscamos ofrecer opciones lindas, creativas y personalizadas para cada ocación, ya sea tu familiar, pareja o amigo.

¿Qué ofrecemos?

Cajas de regalos

Cajas preparadas para cumpleaños, aniversario, fechas especiales y momentos unicos

Regalos personalizadas

Detalles unicos hehcos especialemente para esa persona y esa ocacion.

Ramos

Ramos de flores, chocolates y opciones personalizadas para sorprender.

Nuestra idea

Creamos esta tiendita como parte de un proyecto para aprender a desarrollar páginas web utilizando HTML y CSS.
